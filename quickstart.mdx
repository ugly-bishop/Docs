This quickstart guides you through generating your developer API key, checking wallet balances, verifying recipient account details, and initiating your first payout.

## Prerequisites

Before making requests, ensure you have:

- A registered [Tabs Merchant Account](https://app.tabsglobal.co)
- Your secret API key (`sk_live_...` or `sk_test_...`)
- A command-line terminal with `curl`, or an HTTP client like Postman or Insomnia

---

## Step 1: Generate an API key

1. Log in to the [Tabs Merchant Portal](https://app.tabsglobal.co).
2. In the navigation sidebar, click **Developers**.
3. Select the **API Keys** tab and click **Generate Secret Key**.
4. Choose an environment (**Live** or **Test**), enter a descriptive label (e.g. `Backend API`), and select permissions.
5. Copy your generated key immediately. Tabs displays plaintext keys **only once** for security.

<Warning>
  Never commit your secret API key to version control or expose it in client-side code.
</Warning>

---

## Step 2: Check your wallet balances

Call the `GET /v1/wallets` endpoint to confirm your API key works and view your balances. Amounts are returned in minor currency units (e.g. kobo or cents):

<CodeGroup>
```bash cURL
curl -X GET "https://api.tabsglobal.co/v1/wallets" \
  -H "Authorization: Bearer sk_test_your_secret_key_here" \
  -H "Content-Type: application/json"
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/wallets", {
  method: "GET",
  headers: {
    "Authorization": "Bearer sk_test_your_secret_key_here",
    "Content-Type": "application/json",
  },
});

const wallets = await response.json();
console.log(wallets);
```

```python Python
import requests

url = "https://api.tabsglobal.co/v1/wallets"
headers = {
    "Authorization": "Bearer sk_test_your_secret_key_here",
    "Content-Type": "application/json",
}

response = requests.get(url, headers=headers)
print(response.json())
```
</CodeGroup>

## Step 3: Verify recipient account details

Before sending funds, resolve the recipient's bank account with name enquiry:

<CodeGroup>
```bash cURL
curl -X POST "https://api.tabsglobal.co/v1/payouts/name-enquiry" \
  -H "Authorization: Bearer sk_test_your_secret_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "bankCode": "058",
    "accountNumber": "0123456789"
  }'
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/payouts/name-enquiry", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sk_test_your_secret_key_here",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    bankCode: "058",
    accountNumber: "0123456789",
  }),
});

const verification = await response.json();
console.log(verification.accountName);
```

```python Python
import requests

url = "https://api.tabsglobal.co/v1/payouts/name-enquiry"
headers = {
    "Authorization": "Bearer sk_test_your_secret_key_here",
    "Content-Type": "application/json",
}
payload = {
    "bankCode": "058",
    "accountNumber": "0123456789",
}

response = requests.post(url, headers=headers, json=payload)
print(response.json())
```
</CodeGroup>

### Sample response

```json
{
  "accountNumber": "0123456789",
  "accountName": "ADEWALE ADELEKE",
  "bankCode": "058"
}
```

## Step 4: Initiate an idempotent payout

Execute a payout using a unique `Idempotency-Key` header. This protects your transaction if a network error occurs:

<CodeGroup>
```bash cURL
curl -X POST "https://api.tabsglobal.co/v1/payouts" \
  -H "Authorization: Bearer sk_test_your_secret_key_here" \
  -H "Idempotency-Key: 9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 25000,
    "sourceCurrency": "NGN",
    "payoutCurrency": "NGN",
    "bankCode": "058",
    "accountNumber": "0123456789",
    "recipientName": "ADEWALE ADELEKE",
    "narration": "Contractor invoice #402"
  }'
```

```javascript Node.js
import { randomUUID } from "node:crypto";

const response = await fetch("https://api.tabsglobal.co/v1/payouts", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sk_test_your_secret_key_here",
    "Idempotency-Key": randomUUID(),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    amount: 25000,
    sourceCurrency: "NGN",
    payoutCurrency: "NGN",
    bankCode: "058",
    accountNumber: "0123456789",
    recipientName: "ADEWALE ADELEKE",
    narration: "Contractor invoice #402",
  }),
});

const payout = await response.json();
console.log(payout);
```

```python Python
import uuid
import requests

url = "https://api.tabsglobal.co/v1/payouts"
headers = {
    "Authorization": "Bearer sk_test_your_secret_key_here",
    "Idempotency-Key": str(uuid.uuid4()),
    "Content-Type": "application/json",
}
payload = {
    "amount": 25000,
    "sourceCurrency": "NGN",
    "payoutCurrency": "NGN",
    "bankCode": "058",
    "accountNumber": "0123456789",
    "recipientName": "ADEWALE ADELEKE",
    "narration": "Contractor invoice #402",
}

response = requests.post(url, headers=headers, json=payload)
print(response.json())
```
