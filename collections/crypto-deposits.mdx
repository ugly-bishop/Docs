Tabs enables global businesses to accept deposits in USDT across major blockchain networks.

Each merchant can generate dedicated, persistent deposit addresses tied to their account. When incoming transactions are detected and credited, funds settle directly into your merchant balance.

## Supported blockchain networks

When requesting a crypto deposit address, specify one of the following supported network codes in the `network` field:

| Network Code (`network`) | Blockchain Network | Asset Supported |
| --- | --- | --- |
| `TRON` | Tron Network | USDT (TRC-20) |
| `ETH` | Ethereum Mainnet | USDT (ERC-20) |
| `SOL` | Solana | USDT (SPL) |
| `POLYGON` | Polygon PoS | USDT |
| `BASE` | Base | USDT |
| `ARBITRUM` | Arbitrum One | USDT |

## Generating a deposit address

Call `POST /v1/wallets/crypto-address` with the desired network code:

<CodeGroup>
```bash cURL
curl -X POST "https://api.tabsglobal.co/v1/wallets/crypto-address" \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "network": "TRON"
  }'
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/wallets/crypto-address", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ network: "TRON" }),
});

const depositAddress = await response.json();
console.log(depositAddress);
```

```python Python
import requests

url = "https://api.tabsglobal.co/v1/wallets/crypto-address"
headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json",
}
payload = {"network": "TRON"}

response = requests.post(url, headers=headers, json=payload)
print(response.json())
```
</CodeGroup>

### Sample response

```json
{
  "network": "TRON",
  "asset": "USDT",
  "address": "TLyqzVGLV1nmKBWcDqGzBfZpTXWp4Dk9gM",
  "createdAt": "2026-09-21T01:15:00.000Z"
}
```

<Note>
  Deposit addresses are persistent per network. Re-calling this endpoint with the same network code returns your existing assigned address.
</Note>

## Deposit notifications

When an incoming transfer settles, Tabs credits your balance and dispatches a `deposit.credited` event to your registered webhooks:

```json
{
  "id": "evt_8f1e2d3c-4b5a-6978-0123-456789abcdef",
  "type": "deposit.credited",
  "createdAt": "2026-09-21T02:45:00.000Z",
  "data": {
    "depositId": "dep_crypto_0018273645",
    "currency": "USDT",
    "amount": "5000.00",
    "network": "TRON",
    "txHash": "9b1d...4a8e",
    "senderAddress": "TYL...2k9",
    "creditedAt": "2026-09-21T02:44:58.000Z"
  }
}
```
