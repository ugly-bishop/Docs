Tabs enables global businesses to accept deposits in USD-pegged stablecoins (USDT, USDC) and digital assets across major blockchain networks.

Each merchant can generate dedicated, persistent deposit addresses tied to their account. When incoming transactions achieve the required network confirmations, balances credit automatically to your wallet.

## Supported blockchain networks

| Network Identifier | Network Name | Asset Standard | Confirmations Required |
| --- | --- | --- | --- |
| `TRON` | Tron Network | TRC-20 (USDT) | 19 confirmations (~1 min) |
| `ETHEREUM` | Ethereum Mainnet | ERC-20 (USDT, USDC) | 12 confirmations (~3 mins) |
| `BINANCE_SMART_CHAIN` | BNB Smart Chain | BEP-20 (USDT, USDC) | 15 confirmations (~1 min) |
| `POLYGON` | Polygon PoS | ERC-20 (USDC, USDT) | 64 confirmations (~2 mins) |
| `BITCOIN` | Bitcoin Network | Native BTC | 2 confirmations (~20 mins) |

## Generating a deposit address

Call `POST /v1/wallets/crypto-address` with the desired network to retrieve or generate a dedicated address:

<CodeGroup>
```bash cURL
curl -X POST "https://api.tabsglobal.co/v1/wallets/crypto-address" \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "network": "TRON"
  }'
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/wallets/crypto-address", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ network: "TRON" }),
});

const depositAddress = await response.json();
console.log(depositAddress);
```

```python Python
import requests

url = "https://api.tabsglobal.co/v1/wallets/crypto-address"
headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json",
}
payload = {"network": "TRON"}

response = requests.post(url, headers=headers, json=payload)
print(response.json())
```
</CodeGroup>

### Sample response

```json
{
  "network": "TRON",
  "address": "TLyqzVGLV1nmKBWcDqGzBfZpTXWp4Dk9gM",
  "createdAt": "2026-09-21T01:15:00.000Z"
}
```

<Note>
  Deposit addresses are persistent. Re-calling this endpoint with the same network returns your existing assigned address.
</Note>

## Deposit notifications

When an incoming transfer reaches required block confirmations, your wallet is credited and Tabs dispatches a `deposit.credited` event:

```json
{
  "id": "evt_8f1e2d3c-4b5a-6978-0123-456789abcdef",
  "type": "deposit.credited",
  "createdAt": "2026-09-21T02:45:00.000Z",
  "data": {
    "depositId": "dep_crypto_0018273645",
    "currency": "USDT",
    "amount": "5000.00",
    "network": "TRON",
    "txHash": "9b1d...4a8e",
    "senderAddress": "TYL...2k9",
    "creditedAt": "2026-09-21T02:44:58.000Z"
  }
}
```
