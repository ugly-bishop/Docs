---
title: "Get Payout Details"
sidebarTitle: "Get Payout"
api: "GET /v1/payouts/{id}"
description: "Retrieve real-time status and settlement details for an individual payout."
---

Fetches the complete details and execution breakdown of a single payout by its transaction UUID.

### Scopes required

`payouts:read` or `*`

### Path parameters

<ParamField path="id" type="string" required>
  The unique transaction identifier (e.g. `7d9c0245-31ba-4f27-a0c3-fba4313f89e2`).
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="id" type="string">
  Unique transaction identifier.
</ResponseField>
<ResponseField name="reference" type="string">
  Payout reference code.
</ResponseField>
<ResponseField name="type" type="string">
  Transaction type (`PAYOUT`).
</ResponseField>
<ResponseField name="status" type="string">
  Status: `PROCESSING`, `PENDING`, `SUCCESS`, or `FAILED`.
</ResponseField>
<ResponseField name="currency" type="string">
  Currency code.
</ResponseField>
<ResponseField name="amountMinor" type="string">
  Amount in minor units as string.
</ResponseField>
<ResponseField name="ngnAmountMinor" type="string">
  Total NGN debit in minor units.
</ResponseField>
<ResponseField name="recipient" type="string">
  Beneficiary full legal name.
</ResponseField>
<ResponseField name="metadata" type="object">
  Integration metadata.
</ResponseField>
<ResponseField name="createdAt" type="string">
  Creation timestamp.
</ResponseField>
<ResponseField name="completedAt" type="string">
  Settlement completion timestamp, or null if pending.
</ResponseField>
<ResponseField name="payout" type="object">
  Detailed payout record.
</ResponseField>
