---
title: "Get Payout Details"
sidebarTitle: "Get Payout"
api: "GET /v1/payouts/{id}"
description: "Retrieve real-time status and settlement timeline for an individual payout."
---

Fetches the complete details and delivery timeline of a single payout.

### Scopes required

`payouts:read` or `*`

### Path parameters

<ParamField path="id" type="string" required>
  The unique payout identifier (e.g. `payout_8e16bf9c-6874-4ec5-bda2-1d54e48b81ea`).
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="id" type="string">
  Unique payout identifier.
</ResponseField>
<ResponseField name="status" type="string">
  Current status: `PROCESSING`, `SUCCESS`, or `FAILED`.
</ResponseField>
<ResponseField name="reference" type="string">
  Financial transaction reference.
</ResponseField>
<ResponseField name="amount" type="number">
  Amount dispatched.
</ResponseField>
<ResponseField name="currency" type="string">
  Currency.
</ResponseField>
<ResponseField name="recipientName" type="string">
  Beneficiary full legal name.
</ResponseField>
<ResponseField name="failureReason" type="string">
  Rejection reason if status is `FAILED`.
</ResponseField>
<ResponseField name="completedAt" type="string">
  Timestamp when settlement was finalized.
</ResponseField>
