---

Returns all verified Nigerian commercial and microfinance banks with their canonical 3-digit CBN bank codes and names.

### Scopes required

`payouts:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="banks" type="array">
  List of bank objects.

  <Expandable title="Bank properties">
    <ResponseField name="name" type="string">
      Commercial or legal bank name.
    </ResponseField>
    <ResponseField name="code" type="string">
      3-digit CBN bank code.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tabsglobal.co/v1/payouts/banks" \
  -H "Authorization: Bearer sk_live_..."
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/payouts/banks", {
  method: "GET",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
  },
});

const banks = await response.json();
console.log(banks);
```

```python Python
import requests

response = requests.get(
    "https://api.tabsglobal.co/v1/payouts/banks",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.json())
```
