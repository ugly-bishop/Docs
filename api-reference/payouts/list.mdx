---

Fetches outbound payouts initiated by your merchant account.

### Scopes required

`payouts:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Query parameters

<ParamField query="page" type="integer" default="1">
  Page number (1-indexed).
</ParamField>
<ParamField query="limit" type="integer" default="20">
  Number of records to return per page (max 100).
</ParamField>
<ParamField query="status" type="string">
  Filter by transfer status (`PROCESSING`, `SUCCESS`, `FAILED`).
</ParamField>

### Response

<ResponseField name="data" type="array">
  Array of payout objects.
</ResponseField>
<ResponseField name="pagination" type="object">
  Pagination metadata (`page`, `limit`, `total`, `totalPages`).
</ResponseField>
