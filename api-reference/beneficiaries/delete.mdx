---
title: "Delete a Beneficiary"
sidebarTitle: "Delete Beneficiary"
api: "DELETE /v1/beneficiaries/{id}"
description: "Remove a saved recipient profile from your merchant account."
---

Deletes a saved beneficiary by ID.

### Scopes required

`beneficiaries:write` or `*`

### Path parameters

<ParamField path="id" type="string" required>
  The unique beneficiary identifier.
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  `true` if successfully deleted.
</ResponseField>
<ResponseField name="message" type="string">
  Confirmation message.
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tabsglobal.co/v1/beneficiaries/ben_4a8e2b1c-9f0d-4e5a-8b2c-1d0f3a4b5c6d" \
  -H "Authorization: Bearer sk_live_..."
```
