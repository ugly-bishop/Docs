description: "Retrieve all saved payout beneficiaries for your merchant account."
---

Fetches all saved recipient profiles that you can reuse across multiple payouts.

### Scopes required

`beneficiaries:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="beneficiaries" type="array">
  List of saved beneficiary objects.

  <Expandable title="Beneficiary properties">
    <ResponseField name="id" type="string">
      Unique beneficiary identifier.
    </ResponseField>
    <ResponseField name="type" type="string">
      Beneficiary type (e.g. `BANK_ACCOUNT`, `CRYPTO_WALLET`).
    </ResponseField>
    <ResponseField name="details" type="object">
      Bank or wallet details (account number, bank code, legal name, currency).
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      Timestamp when the beneficiary was created.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tabsglobal.co/v1/beneficiaries" \
  -H "Authorization: Bearer sk_live_..."
```

