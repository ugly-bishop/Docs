---

Saves a recipient's banking or wallet credentials to your merchant profile.

### Scopes required

`beneficiaries:write` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Body

<ParamField body="type" type="string" required>
  Recipient category: `BANK_ACCOUNT` or `CRYPTO_WALLET`.
</ParamField>
<ParamField body="details" type="object" required>
  Corridor specific beneficiary details.

  <Expandable title="Details properties">
    <ParamField body="accountName" type="string" required>
      Verified account holder legal name.
    </ParamField>
    <ParamField body="accountNumber" type="string" required>
      Bank account number or IBAN.
    </ParamField>
    <ParamField body="bankCode" type="string">
      3-digit CBN bank code (for NGN).
    </ParamField>
    <ParamField body="currency" type="string" required>
      Settlement currency code (`NGN`, `USD`, `EUR`, `GBP`).
    </ParamField>
  </Expandable>
</ParamField>

### Response

<ResponseField name="id" type="string">
  Unique beneficiary identifier.
</ResponseField>
<ResponseField name="type" type="string">
  Beneficiary type.
</ResponseField>
<ResponseField name="details" type="object">
  Saved recipient details.
</ResponseField>
<ResponseField name="createdAt" type="string">
  Creation timestamp.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tabsglobal.co/v1/beneficiaries",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "type": "BANK_ACCOUNT",
        "details": {
            "accountName": "ADEWALE ADELEKE",
            "accountNumber": "0123456789",
            "bankCode": "058",
            "currency": "NGN",
        },
    },
)
print(response.json())
```
