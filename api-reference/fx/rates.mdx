Fetches current real-time exchange rates with merchant markups across supported payout currencies (`USD`, `GBP`, `EUR`).

### Scopes required

`fx:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="rates" type="object">
  Map of currency codes (`USD`, `GBP`, `EUR`) to their buy, sell rates and fixed rail fees.

  <Expandable title="Rate object properties">
    <ResponseField name="buy" type="number">
      Customer buy rate (inbound conversion rate to NGN).
    </ResponseField>
    <ResponseField name="sell" type="number">
      Customer sell rate (outbound conversion rate from NGN).
    </ResponseField>
    <ResponseField name="fixedFee" type="number">
      Fixed corridor transfer fee in NGN major units.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tabsglobal.co/v1/fx/rates" \
  -H "Authorization: Bearer sk_live_..."
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/fx/rates", {
  method: "GET",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
  },
});

const rates = await response.json();
console.log(rates);
```

```python Python
import requests

response = requests.get(
    "https://api.tabsglobal.co/v1/fx/rates",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.json())
```
</RequestExample>
