---

Fetches current real-time exchange rates across all supported currency pairs.

### Scopes required

`fx:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="rates" type="object">
  Map of currency pairs and their current exchange rates against base currencies.
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tabsglobal.co/v1/fx/rates" \
  -H "Authorization: Bearer sk_live_..."
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/fx/rates", {
  method: "GET",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
  },
});

const rates = await response.json();
console.log(rates);
```

```python Python
import requests

response = requests.get(
    "https://api.tabsglobal.co/v1/fx/rates",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.json())
```
</RequestExample>
