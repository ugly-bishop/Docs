---
title: "Request Forward FX Quote"
sidebarTitle: "Forward Quote"
api: "POST /v1/fx/quotes/forward"
description: "Specify the exact foreign source wallet amount to debit and calculate the resulting converted NGN amount."
---

Calculates the recipient NGN settlement amount based on the exact amount debited from a foreign currency wallet (`USD`, `GBP`, `EUR`).

### Scopes required

`fx:write` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Body

<ParamField body="sourceCurrency" type="string" required>
  The source foreign currency being spent (`USD`, `GBP`, `EUR`).
</ParamField>
<ParamField body="sourceDebitAmount" type="number" required>
  Exact amount in major units to debit from the source wallet (e.g. `5000` for 5,000 USD).
</ParamField>

### Response

<ResponseField name="quoteId" type="string">
  Unique quote identifier.
</ResponseField>
<ResponseField name="currency" type="string">
  Source currency code.
</ResponseField>
<ResponseField name="direction" type="string">
  Quote direction (`FOREIGN_TO_NGN`).
</ResponseField>
<ResponseField name="foreignAmountMinor" type="string">
  Net foreign amount converted after subtracting corridor fees.
</ResponseField>
<ResponseField name="rate" type="number">
  Locked buy exchange rate.
</ResponseField>
<ResponseField name="transferFeeMinor" type="string">
  Corridor transfer fee converted to foreign currency minor units.
</ResponseField>
<ResponseField name="ngnAmountMinor" type="string">
  Calculated NGN amount credited to recipient in minor units.
</ResponseField>
<ResponseField name="totalDebitMinor" type="string">
  Total foreign currency amount debited in minor units.
</ResponseField>
<ResponseField name="expiresAt" type="string">
  ISO expiration timestamp.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tabsglobal.co/v1/fx/quotes/forward" \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "sourceCurrency": "USD",
    "sourceDebitAmount": 5000
  }'
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/fx/quotes/forward", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    sourceCurrency: "USD",
    sourceDebitAmount: 5000,
  }),
});

const quote = await response.json();
console.log(quote);
```

```python Python
import requests

response = requests.post(
    "https://api.tabsglobal.co/v1/fx/quotes/forward",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={"sourceCurrency": "USD", "sourceDebitAmount": 5000},
)
print(response.json())
```
