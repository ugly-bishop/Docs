title: "Request Guaranteed FX Quote"
sidebarTitle: "Create Quote"
api: "POST /v1/fx/quotes"
description: "Lock in an institutional exchange rate for a foreign currency amount with a 60-second validity countdown."
---

Locks in an exchange rate for a specified foreign amount. Returns a quote with amounts in minor units that can be passed to payouts before expiration.

### Scopes required

`fx:write` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Body

<ParamField body="currency" type="string" required>
  Foreign payout currency (`USD`, `GBP`, `EUR`).
</ParamField>
<ParamField body="foreignAmount" type="number" required>
  Amount in foreign currency major units (e.g. `5000` for 5,000 USD).
</ParamField>

### Response

<ResponseField name="quoteId" type="string">
  Unique quote identifier.
</ResponseField>
<ResponseField name="currency" type="string">
  Currency quoted.
</ResponseField>
<ResponseField name="direction" type="string">
  Quote direction (`NGN_TO_FOREIGN`).
</ResponseField>
<ResponseField name="foreignAmountMinor" type="string">
  Target foreign currency amount in minor units as a string.
</ResponseField>
<ResponseField name="rate" type="number">
  Locked exchange rate.
</ResponseField>
<ResponseField name="transferFeeMinor" type="string">
  Corridor transfer fee in NGN minor units.
</ResponseField>
<ResponseField name="ngnAmountMinor" type="string">
  Calculated total in Nigerian Naira (NGN) minor units.
</ResponseField>
<ResponseField name="totalDebitMinor" type="string">
  Total NGN amount to debit (amount + fee) in minor units.
</ResponseField>
<ResponseField name="expiresAt" type="string">
  ISO timestamp when the 60-second rate lock expires.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tabsglobal.co/v1/fx/quotes" \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "currency": "USD",
    "foreignAmount": 5000
  }'
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/fx/quotes", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    currency: "USD",
    foreignAmount: 5000,
  }),
});

const quote = await response.json();
console.log(quote);
```

```python Python
import requests

response = requests.post(
    "https://api.tabsglobal.co/v1/fx/quotes",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={"currency": "USD", "foreignAmount": 5000},
)
print(response.json())
```
