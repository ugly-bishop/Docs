---

Calculates the exact foreign currency debit needed to deliver a target Nigerian Naira (NGN) payout.

### Scopes required

`fx:write` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Body

<ParamField body="sourceCurrency" type="string" required>
  The source foreign currency being debited (`USD`, `GBP`, `EUR`).
</ParamField>
<ParamField body="targetNgnAmount" type="number" required>
  Exact target amount in NGN major units to be received.
</ParamField>

### Response

<ResponseField name="quoteId" type="string">
  Unique quote identifier.
</ResponseField>
<ResponseField name="currency" type="string">
  Source foreign currency code.
</ResponseField>
<ResponseField name="direction" type="string">
  Quote direction (`FOREIGN_TO_NGN`).
</ResponseField>
<ResponseField name="foreignAmountMinor" type="string">
  Net foreign currency amount needed in minor units.
</ResponseField>
<ResponseField name="rate" type="number">
  Locked buy exchange rate.
</ResponseField>
<ResponseField name="transferFeeMinor" type="string">
  Corridor transfer fee converted to foreign currency minor units.
</ResponseField>
<ResponseField name="ngnAmountMinor" type="string">
  Target NGN amount in minor units.
</ResponseField>
<ResponseField name="totalDebitMinor" type="string">
  Total foreign currency amount required to debit in minor units.
</ResponseField>
<ResponseField name="expiresAt" type="string">
  ISO expiration timestamp.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tabsglobal.co/v1/fx/quotes/inverse" \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "sourceCurrency": "USD",
    "targetNgnAmount": 5000000
  }'
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/fx/quotes/inverse", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    sourceCurrency: "USD",
    targetNgnAmount: 5000000,
  }),
});

const quote = await response.json();
console.log(quote);
```

```python Python
import requests

response = requests.post(
    "https://api.tabsglobal.co/v1/fx/quotes/inverse",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={"sourceCurrency": "USD", "targetNgnAmount": 5000000},
)
print(response.json())
```
