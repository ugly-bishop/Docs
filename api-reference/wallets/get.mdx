description: "Retrieve balance and details for a specific currency."
---

Fetches the balance of a single currency wallet by its currency code.

### Scopes required

`wallets:read` or `*`

### Path parameters

<ParamField path="currency" type="string" required>
  The uppercase currency code (e.g. `NGN`, `USD`).
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="id" type="string">
  Unique wallet UUID.
</ResponseField>
<ResponseField name="currency" type="string">
  The requested currency code.
</ResponseField>
<ResponseField name="balanceMinor" type="string">
  Current balance in minor units (e.g. `145000000` = 1,450,000.00 NGN).
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tabsglobal.co/v1/wallets/NGN" \
  -H "Authorization: Bearer sk_live_..."
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/wallets/NGN", {

  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,

});

const data = await response.json();
```

