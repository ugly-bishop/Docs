---

Generates or fetches the merchant's dedicated cryptocurrency deposit address for the specified blockchain network.

### Scopes required

`wallets:write` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Body

<ParamField body="network" type="string" required>
  The target blockchain network: `TRON`, `ETHEREUM`, `BINANCE_SMART_CHAIN`, `POLYGON`, or `BITCOIN`.
</ParamField>

### Response

<ResponseField name="network" type="string">
  The requested network identifier.
</ResponseField>
<ResponseField name="address" type="string">
  The multi-chain deposit address.
</ResponseField>
<ResponseField name="createdAt" type="string">
  ISO timestamp when the address was allocated.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tabsglobal.co/v1/wallets/crypto-address" \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "network": "TRON"
  }'
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/wallets/crypto-address", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ network: "TRON" }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    "https://api.tabsglobal.co/v1/wallets/crypto-address",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={"network": "TRON"},
)
print(response.json())
```
