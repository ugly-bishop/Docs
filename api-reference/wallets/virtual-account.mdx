Retrieves the merchant assigned Nigerian virtual bank account details for receiving fiat NGN deposits.

### Scopes required

`wallets:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="accountNumber" type="string">
  The 10-digit NUBAN virtual account number.
</ResponseField>
<ResponseField name="accountName" type="string">
  The legal beneficiary title assigned to this virtual account.
</ResponseField>
<ResponseField name="bankName" type="string">
  The partner financial institution holding the NUBAN.
</ResponseField>
<ResponseField name="bankCode" type="string">
  3-digit CBN bank code.
</ResponseField>
<ResponseField name="currency" type="string">
  Currency of inbound settlement (`NGN`).
</ResponseField>
<ResponseField name="status" type="string">
  Account status (`ACTIVE`, `SUSPENDED`).
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tabsglobal.co/v1/wallets/virtual-account" \
  -H "Authorization: Bearer sk_live_..."
```

```javascript Node.js
const response = await fetch("https://api.tabsglobal.co/v1/wallets/virtual-account", {
  method: "GET",
  headers: {
    "Authorization": `Bearer ${process.env.TABS_SECRET_KEY}`,
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.tabsglobal.co/v1/wallets/virtual-account",
    headers={"Authorization": f"Bearer {API_KEY}"},
)
print(response.json())
```
