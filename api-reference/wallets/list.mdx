---

Returns balances across all active currency wallets associated with your merchant account.

### Scopes required

`wallets:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="wallets" type="array">
  List of wallet balance objects.

  <Expandable title="Wallet properties">
    <ResponseField name="currency" type="string">
      ISO currency code or cryptocurrency symbol (e.g. `NGN`, `USD`, `USDT`).
    </ResponseField>
    <ResponseField name="balance" type="string">
      Total balance in major units.
    </ResponseField>
    <ResponseField name="availableBalance" type="string">
      Spendable balance available for payouts and currency swaps.
    </ResponseField>
    <ResponseField name="ledgerBalance" type="string">
      Gross ledger balance including pending incoming settlements.
    </ResponseField>
  </Expandable>
</ResponseField>
