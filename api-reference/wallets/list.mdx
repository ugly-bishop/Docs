sidebarTitle: "List Wallets"
api: "GET /v1/wallets"
description: "Retrieve balances across all active merchant wallets."
---

Returns balances across all active currency wallets associated with your merchant account. Amounts are represented in minor currency units (e.g. kobo or cents as strings).

### Scopes required

`wallets:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="wallets" type="array">
  List of wallet objects.

  <Expandable title="Wallet properties">
    <ResponseField name="id" type="string">
      Unique wallet UUID.
    </ResponseField>
    <ResponseField name="currency" type="string">
      Currency code (e.g. `NGN`, `USD`).
    </ResponseField>
    <ResponseField name="balanceMinor" type="string">
      Current balance in minor units (e.g. `145000000` = 1,450,000.00 NGN).
    </ResponseField>
  </Expandable>
</ResponseField>
