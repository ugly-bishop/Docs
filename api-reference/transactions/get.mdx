---
title: "Get Transaction Receipt"
sidebarTitle: "Get Transaction"
api: "GET /v1/transactions/{idOrReference}"
description: "Retrieve complete details, ledger settlement status, and receipt for a single transaction."
---

Fetches detailed ledger information and receipt data by transaction UUID or merchant reference string.

### Scopes required

`transactions:read` or `*`

### Path parameters

<ParamField path="idOrReference" type="string" required>
  The transaction UUID or unique reference string (e.g. `TABS_PO_1726884000123`).
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Response

<ResponseField name="id" type="string">
  Unique transaction identifier.
</ResponseField>
<ResponseField name="reference" type="string">
  Financial reference.
</ResponseField>
<ResponseField name="type" type="string">
  Transaction type (`DEPOSIT`, `PAYOUT`, `FX_SWAP`).
</ResponseField>
<ResponseField name="status" type="string">
  Final settlement status (`SUCCESS`, `PENDING`, `FAILED`).
</ResponseField>
<ResponseField name="currency" type="string">
  Currency code.
</ResponseField>
<ResponseField name="amountMinor" type="string">
  Amount in minor units (e.g. kobo or cents).
</ResponseField>
<ResponseField name="recipient" type="object">
  Beneficiary or counterparty details.
</ResponseField>
<ResponseField name="completedAt" type="string">
  Settlement timestamp.
</ResponseField>
