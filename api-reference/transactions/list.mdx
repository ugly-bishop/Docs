---

Returns a paginated list of financial ledger transactions (deposits, payouts, FX conversions) for your merchant account.

### Scopes required

`transactions:read` or `*`

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer API secret key formatted as `Bearer sk_live_...` or `Bearer sk_test_...`.
</ParamField>

### Query parameters

<ParamField query="page" type="integer" default="1">
  Page number (1-indexed).
</ParamField>
<ParamField query="limit" type="integer" default="20">
  Number of items per page (maximum 100).
</ParamField>
<ParamField query="type" type="string">
  Filter by transaction type (`DEPOSIT`, `PAYOUT`, `FX_SWAP`).
</ParamField>
<ParamField query="currency" type="string">
  Filter by currency code (e.g. `NGN`, `USD`).
</ParamField>
<ParamField query="status" type="string">
  Filter by status (`PENDING`, `SUCCESS`, `FAILED`).
</ParamField>

### Response

<ResponseField name="data" type="array">
  Array of ledger transaction objects.
</ResponseField>
<ResponseField name="pagination" type="object">
  Pagination details (`page`, `limit`, `total`, `totalPages`).
</ResponseField>
